# Tounsi AI Studio — V1

موقع ويب متجاوب مع الهاتف والكمبيوتر لإنشاء فيديوهات عمودية بسيطة من نصّ: كوميديا تونسية، محتوى ديني، ومحتوى تعليمي.

## الموجود في النسخة
- واجهة عربية متجاوبة.
- قوالب نصوص محلية أولية (لا تحتاج مفتاح API مدفوع).
- تحويل النص إلى فيديو عمودي MP4 مع صوت عربي عبر gTTS.
- تنزيل الفيديو.
- مسار فحص صحة الخادم `/health`.
- إعدادات Render عبر `render.yaml`.

## مهم قبل النشر
- الصوت عبر gTTS يحتاج اتصال إنترنت من الخادم وقد يتوقف مؤقتًا حسب توفر الخدمة.
- النسخة لا تستخدم نموذج توليد فيديو سينمائي؛ تصدّر فيديو بطاقة نصية ثابتة مع تعليق صوتي.
- النشر التلقائي إلى YouTube غير مفعّل في هذه النسخة. يلزمه OAuth من Google وتخزين الأسرار في إعدادات الاستضافة، ولا تضع الأسرار في GitHub.
- الخطة المجانية قد تنام بعد عدم الاستخدام، وقد تكون لها حدود وقت/ذاكرة؛ الفيديوهات تُحفظ مؤقتًا على الخادم وقد تختفي عند إعادة التشغيل.
- اختبر الرابط `/health` ثم أنشئ فيديو تجريبي قبل مشاركة الموقع.

## تشغيل محلي
```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
python app.py
```
ثم افتح `http://127.0.0.1:5000`.

## النشر من الهاتف عبر GitHub + Render
1. أنشئ مستودع GitHub جديدًا باسم `tounsi-ai-studio`، منفصلًا عن `youtube-bot-hamdi`.
2. ارفع كل ملفات هذا المجلد إلى المستودع الجديد.
3. في Render اختر **New + → Blueprint** واربط المستودع الجديد، أو اختر **Web Service** ثم استخدم Build Command `pip install -r requirements.txt` وStart Command `gunicorn app:app --workers 1 --threads 2 --timeout 180`.
4. بعد النشر افتح رابط Render، ثم `/health` للتأكد من عمل الخادم.

## الأمان
لا ترفع مفاتيح API أو ملفات OAuth أو `.env` إلى GitHub.
