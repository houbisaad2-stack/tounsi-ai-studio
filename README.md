# Tounsi AI Studio

موقع ويب متجاوب لإنشاء فيديوهات قصيرة عمودية ثم رفعها إلى قناة YouTube بعد ربط القناة يدويًا.

## الموجود حاليًا
- قوالب نصوص تونسية محلية؛ هذه ليست كتابة مولّدة بنموذج ذكاء اصطناعي.
- تصدير MP4 من بطاقة نصية، أو من صور، أو من مقاطع فيديو يرفعها المستخدم.
- صوت عربي عبر خدمات TTS مجانية عند توفرها؛ قد يتعذّر الصوت، والخادم يحاول مواصلة التصدير بدونه.
- ربط قناة YouTube عبر Google OAuth.
- رفع الفيديو يدويًا بزرّ النشر مع اختيار الخصوصية؛ الخصوصية الافتراضية Private.
- حماية واجهة النشر بكلمة مرور في متغير البيئة `PUBLISH_PASSWORD`.

## إعداد YouTube مرة واحدة
1. افتح Google Cloud Console: https://console.cloud.google.com/
2. أنشئ مشروعًا، وفعّل **YouTube Data API v3**.
3. جهّز شاشة OAuth consent. إذا كان التطبيق External وفي وضع Testing، أضف حساب Google الذي سيُربط بالقناة إلى Test users.
4. أنشئ OAuth Client ID من نوع **Web application**.
5. في Authorized redirect URIs أضف رابط موقع Render متبوعًا بـ `/youtube/callback`، مثل:
   `https://YOUR-SERVICE.onrender.com/youtube/callback`
6. انسخ ملف JSON الخاص ببيانات OAuth. في Render → الخدمة → Environment، أضف:
   - `YOUTUBE_CLIENT_JSON`: محتوى ملف OAuth JSON كاملًا.
   - `PUBLISH_PASSWORD`: كلمة مرور قوية من اختيارك لحماية النشر.
   - `APP_SECRET_KEY`: قيمة عشوائية طويلة وفريدة.
7. احفظ التغييرات وانتظر إعادة النشر.
8. افتح الموقع واضغط **اربط قناة YouTube**، سجّل الدخول ووافق على الصلاحيات.
9. أنشئ فيديو، أدخل كلمة مرور النشر، ثم اضغط النشر. ابدأ بخصوصية **Private** للتحقق قبل جعله عامًا.

## ملاحظات مهمّة
- لا تضع Client Secret أو OAuth token أو أي مفتاح داخل ملفات GitHub أو داخل واجهة HTML.
- Render Free يستخدم تخزينًا مؤقتًا؛ رمز الاتصال الذي ينشأ أثناء OAuth محفوظ في مساحة مؤقتة وقد يضيع عند إعادة تشغيل الخدمة. عندها قد تحتاج إلى إعادة ربط القناة. تخزين دائم يحتاج قاعدة بيانات أو تخزين أسرار مناسبًا.
- لا تترك كلمة مرور النشر ظاهرة على جهاز مشترك. لا تشاركها في المحادثة.
- النشر الآلي التلقائي دون الضغط على الزر ليس مفعّلًا بعد؛ النسخة الحالية ترفع الفيديو بعد تأكيد المستخدم.
- رفع الفيديو يخضع لحصص Google/YouTube، وسياسات القناة، وحالة OAuth consent.
- صناعة مشاهد فيديو أصلية بالذكاء الاصطناعي لم تُفعّل بعد؛ الفيديو الحالي مبني على نصوص وصور أو مقاطع يرفعها المستخدم.
- خطة Render المجانية قد تنام أو تعيد تشغيل الخدمة، وملفات MP4 المؤقتة يمكن أن تختفي.

## فحص الخدمة
- `/health` يعرض حالة الخادم.
- `/api/youtube/status` يعرض هل إعداد OAuth موجود وهل القناة متصلة، من دون إظهار أسرار.

## تشغيل محلي
```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
python app.py
```
